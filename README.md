## About Me

I'm a **Computer Science graduate and Software Engineer** focused on
**full-stack development, AI/ML, backend engineering, and automation**.

I build production-style applications that combine modern web technologies,
RESTful APIs, databases, AI services, cloud platforms, and CI/CD pipelines.
My work spans both **MERN-based applications** and **Python-based backend
systems**, with a growing focus on scalable architectures and DevOps practices.

I've built and deployed full-stack applications, AI-powered systems,
REST APIs, database-driven platforms, and cloud-hosted projects.

### What I Do

- Build full-stack web applications and RESTful APIs
- Develop Python and JavaScript backend systems
- Integrate AI/ML models and LLM-powered features
- Work with relational and NoSQL databases
- Deploy applications using cloud and CI/CD technologies
- Build automation and developer workflows
- Explore scalable backend and system architectures

### What I've Built

A full-stack AI application combining React, FastAPI, PostgreSQL,
RAG, vector databases, LLMs, speech processing, and image understanding.

**Risuto — Anime Tracking Platform**  
A MERN-based application built with React, Node.js, Express,
MongoDB, and deployed cloud infrastructure.

**Personal Portfolio**

### Currently Working On
